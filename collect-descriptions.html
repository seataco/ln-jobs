Read the descriptions without saving each job

A saved search page only includes the description of the job LinkedIn already opened. This collector walks the jobs already loaded on that search and downloads one file.

  1. Open the LinkedIn job search and scroll until the jobs you want are on the page.
  2. Press F12, open Console, and type allow pasting if the console asks.
  3. Click the button below, then paste into that console and press Enter.
  4. Wait until a file downloads. A 25-job list takes about a minute.
  5. Put that file in the inbox folder and run run.bat.

It only reads the search you already have open. It does not log in or send the jobs anywhere. Keep the tab in front while it runs. LinkedIn can dislike a script clicking a very long list, so use the jobs on one loaded page rather than hundreds.
